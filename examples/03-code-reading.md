```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SelfAttention(nn.Module):
    def __init__(self, d_model, d_k):
        super().__init__()
        self.W_q = nn.Linear(d_model, d_k)
        self.W_k = nn.Linear(d_model, d_k)
        self.W_v = nn.Linear(d_model, d_k)
        self.d_k = d_k

    def forward(self, x):
        Q = self.W_q(x)
        K = self.W_k(x)
        V = self.W_v(x)
        scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
        weights = F.softmax(scores, dim=-1)
        return weights @ V
```

### 1.5.A 核心创新（vs 朴素写法）

朴素 sequence 处理通常用 RNN（按时间步循环）或固定窗口的 CNN（局部卷积）。本代码实现 **scaled dot-product self-attention**：让每个位置直接跟所有其它位置计算相关度，权重再加权 V。**关键差异**：不需要循环、不受局部窗口限制，并行友好。

### 1.5.C 关键代码片段

```python
def forward(self, x):
    Q = self.W_q(x)         # 把输入剁成"查"——孙儿想问啥
    K = self.W_k(x)         # 把输入剁成"被查"——桌上摆着啥
    V = self.W_v(x)         # 把输入剁成"答案"——大爷端啥菜上桌

    # 大爷扫桌：让每个"查"跟所有"被查"配对算关注度
    scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
    # 上面那个除以 sqrt(d_k) 是怕分数太大（softmax 容易"梭哈"），先把分数压一压

    # 决定先理谁：softmax 把分数挤成 0~1 的"先后序"
    weights = F.softmax(scores, dim=-1)

    # 大爷端菜：按先后序加权拼答案
    return weights @ V
```

### 1.5.D 一句话串起来

一句话攥住——`Q/K/V` 三个 Linear 就是"**把面剁成三块**"，`Q @ K.T` 就是"**大爷扫桌配对**"，`softmax / sqrt(d_k)` 是"**掂量先后**"，`weights @ V` 是"**端菜上桌**"。新在 dispense with recurrence——并行算，不排队。
